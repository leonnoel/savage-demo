Project: savage-demo

Savage demo is demo a project for 21 savage funs where they interact by writing messages and others can like, dislike and delete the from the DOM.

How It's Made: 
Tech used: HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

Lessons Learned: I learned ho to make thumbsUP, thumbsDown and delete button working.
